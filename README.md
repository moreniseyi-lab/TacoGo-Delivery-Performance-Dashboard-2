# 🌮 TacoGo Delivery Performance Dashboard

Power BI dashboard analyzing 1,000 taco delivery orders across 10 restaurants.

**Live Project:** 2024-2025 Delivery Operations

### 📊 Key Metrics
- **Total Orders:** 1K ( +43.3% YoY )
- **Total Revenue:** $6.91K ( +43.6% YoY )
- **Avg Delivery Duration:** 50.93 mins ( -0.3% YoY - improved! )
- **Total Tips:** $1.81K ( +45.6% YoY )

### 🔍 Key Insights
- **Top Performing Restaurant:** Urban Tacos - 117 orders, $794.50 revenue
- **Slowest Delivery:** The Taco Stand - 53.56 mins avg (needs optimization)
- **Fastest Delivery:** La Vida Taco - 47.05 mins avg (best practice)
- **Most Popular:** Chicken Taco (218 orders, 22%) & Beef Taco (211 orders, 21%)
- **Revenue Drop Alert:** Orders declined sharply after Feb 2025 (from 50 to <20) - seasonality or operational issue?

### 📈 Dashboard Pages
1.  **Home:** KPIs, Orders by Restaurant, Taco Type Distribution, Revenue by Size, Orders by Month
2.  **More Insights:** Revenue by Month, Avg Delivery Duration by Restaurant, Tips Trend, Detailed Table with YoY Change

### 🛠️ Tools Used
Power BI Desktop | DAX (YoY % Change) | Data Modeling | Bar, Donut & Line Charts | Slicers (Year, Restaurant, Taco Type)
